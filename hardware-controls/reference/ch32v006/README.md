# CH32V006 参考资料

官方产品及资料入口：https://www.wch.cn/products/CH32V006.html 和 https://www.wch.cn/downloads/CH32V006DS0_PDF.html

本地 CH32V006DS0.pdf 为 WCH 数据手册 V2.0，下载镜像：https://ch32-riscv-ug.github.io/CH32V006/datasheet_en/CH32V006DS0.PDF 。V2.0 的 QFN20 型号写作 F8U7。本板选用 F8U6，其引脚与封装另按 WCH V1.7 校对：https://manuals.plus/m/1cc33839ba2672a2122e25928cc88d01f81bcbcd1af694f93978742c9ab24e1f.pdf 。不要仅根据 V2.0 的后缀推断采购型号。

CH32V00XRM.pdf 为系列参考手册。TXT 是 PDF 文本提取辅助文件，封装方向与引脚应以图纸为准。

官方 SDK：https://github.com/openwch/ch32v002_004_005_006_007 。本机 MounRiver Studio 2 的 SDK 中也有 CH32V006/NoneOS/TouchKey/CH32V006F8U.zip，包含三电极滑轮插值函数。该示例不是本板可直接烧录的成品固件。

新的 CH32V006_QFN20.step 为根据封装尺寸建立的名义模型，用于显示体积；它不是厂商认证的装配模型或推荐焊盘图。
