## 手动布线规划

1. 先完成 U3、U4、U16 的输入去耦和开关回路；控制 SW 铜面积，反馈和音频信号避开开关节点。根据实际电流确定电感／功率焊盘铜宽及热过孔。
2. 完成 U2 的去耦、充电泵、晶振和耳机模拟输出。背面的 C28 用短电源过孔连接 U2.4，就近接完整地参考面；不要经长电源支线串接后再去耦。
3. USB 从 USB1 经 D1 再到 U17，随后分往 ESP32 和 CH343。尽量减少跨层、保持连续地参考，并按板厂实际六层叠层确定差分线宽／间距。平面距离接近并不等于差分已经等长。
4. H2 的 GBAT 载流连接经过 R1；U14 电流测量采用从采样电阻焊盘引出的独立采样路径，避免将压降和大电流回流混入测量连接。电池 NTC 线沿低速区域走向 U3.TS。
5. 再处理 I²S、QSPI、SDIO 与低速控制，最后完善电源／地铜及回流过孔。保持天线双面禁布约束，操作小板 FPC 通道不得被器件占用。

布局参考：[KiCad PCB 关联与更新](https://docs.kicad.org/10.0/en/pcbnew/pcbnew.html)、[BQ25895 数据手册的布局章节](https://www.ti.com/lit/ds/symlink/bq25895.pdf)、[CS43131 数据手册](https://statics.cirrus.com/pubs/proDatasheet/CS43131_DS1155F2.pdf)、[STC3115 系统集成指南](https://www.st.com/resource/en/application_note/an4324-stc3115-system-integration-stmicroelectronics.pdf)。
