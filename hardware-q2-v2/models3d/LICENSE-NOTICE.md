# 3D model sources and attribution

This directory includes models carried forward from the project's earlier KiCad assemblies. KiCad-derived models retain the original copyright and attribution in their STEP headers and use **CC-BY-SA 4.0 with the KiCad electronic-design exception**. See [KiCad library licensing](https://www.kicad.org/libraries/license/) and [CC-BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/legalcode). The earlier model provenance is retained in Git history at `7d2b1bb:hardware-q2/models3d/LICENSE-NOTICE.md` and its companion model manifest.

Project-generated connector and package envelopes are approximate mechanical models, not supplier-certified geometry. The new ESP32-S31 and crystal envelopes are generated by the scripts in this project; they use the same CC-BY-SA 4.0 terms with the electronic-design exception. Heights, contacts and insertion clearances require verification against ordered parts.

Models referenced through `KICAD10_3DMODEL_DIR` remain in the user's official KiCad installation and are not copied into this directory. The final list of referenced model files is recorded in `../output/model-audit.json`.
