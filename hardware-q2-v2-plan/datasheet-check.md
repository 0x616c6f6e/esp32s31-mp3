# ESP32-S31 芯片手册核对 · 布局规划 B

来源：项目根目录 `esp32-s31_datasheet_en.pdf`，Pre-release v0.5 / PRELIMINARY，110页。本文使用实际文件内容，不把它当作已定版的量产规格。

## 已确认的尺寸和型号

手册第16页表1-1列出 ESP32-S31NRV16（16 MB PSRAM）和 ESP32-S31NRV32（32 MB PSRAM）。规划按与原模组PSRAM容量一致的NRV16作为候选，尚未决定采购型号；两者在该表中均为QFN80 8×8 mm。

第104页图7-1：

| 项目 | 尺寸，mm |
|---|---|
| 本体 | 8×8，BSC |
| 引脚间距 | **0.35，BSC** |
| 整体高度 | 最小0.80，典型0.85，最大0.90 |
| 裸露散热焊盘 | 典型6.5×6.5；尺寸范围6.4–6.6 |
| 引脚金属宽度 | 0.12–0.22，典型0.17 |
| 引脚金属长度 | 0.30–0.50，典型0.40 |

以上是器件封装尺寸，**不是PCB推荐焊盘或钢网尺寸**。尤其不可用普通0.4 mm间距QFN80替代。PCB中央焊盘分窗、散热过孔和外周焊盘仍须结合参考设计与贴装工艺设计。

## 更新到规划工程的位置

按KiCad顶视图、板框左上角为原点：

| 对象 | X / Y | 方向及用途 |
|---|---|---|
| 裸芯片本体候选 | **30.00 / 17.00** | **−90°**；绝对坐标158.868 / 84.647 |
| 本体范围 | X26–34、Y13–21 | 8×8的文档层外形，不是电气封装 |

第17页图2-1给出标准顶视图。以上芯片−90°表示从该图顺时针旋转90°：**芯片1脚角在右上**，与BTB当前1脚左下的描述不是同一个器件。

| 接口组 | 芯片物理引脚 | 候选旋转后的方向 |
|---|---|---|
| ANT | 1 | 上侧靠右，朝RF预留区 |
| SDIO | 27/28/29/31/32/33 | 左侧，朝TF卡；不是旧模组焊盘号 |
| 启动Flash | 36/37/38/40/41/42 | 左下角，横跨左侧下段和底边左段 |

这是固定功能引脚与机械位置的协调候选。屏幕QSPI、I²S和其他GPIO已有候选分配，见 `pin-assignment.md`；尚未同步到原理图/PCB，不能声称所有信号已消除交叉。

## 下一版原理图必须补齐的内容

1. 第35页明确要求封装外Flash，最大支持256 MB；NRV16/NRV32后缀指的是PSRAM容量。原U10 W25Q16JV只有16 Mbit，即2 MB。不能自动将它视为原模组16 MB Flash的等效替代，容量与芯片选型仍需决定。
2. 第33–35页分别列出PSRAM、Flash、SD和其他电源域。VDD_PSRAM_1P8_1/2、VDD_LDO_1P8、VDD_SPI不能仅因都叫“电源”就并到3.3 V。按已验证的参考电路安排去耦和供电连接。
3. 第36–38页涉及GPIO36、GPIO37、GPIO60、GPIO61的启动配置。GPIO36涉及Flash电压选择；BOOT和复位电路必须按裸芯片物理引脚重新建立。不要从旧模组引脚编号直接复制。
4. 第104页是封装机械图，没有给出完整推荐land pattern。此版本仅在文档层添加本体轮廓，并在FreeCAD增加8×8×0.9 mm占位，未生成80个未验证的铜焊盘，也未建立裸芯片网络。

当前仍是布局规划。新外形占位可用于装配空间检查，但不代表配套器件、射频天线或屏幕原生排线已经完成设计。

检查中同时修正了原U10占位STEP与封装引脚跨距方向相差90°的问题，KiCad模型旋转和FreeCAD装配已同步。模型仍为名义外形，并非完整厂家模型。
