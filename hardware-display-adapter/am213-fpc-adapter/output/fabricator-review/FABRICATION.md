# AM213 A — FPC 制造审核与样板说明

用于双层柔性板工艺审核及首次样板。**不要按普通 1.6 mm 刚性 PCB 下单，也不要把 87×22 mm 外包矩形做成整板。** GM1/Edge.Cuts 是实际板框。

## 结构

- 元件岛 17×22 mm；左出尾巴 70 mm、主体宽 6.60 mm；根部最后 2 mm 扩展。
- 双层 PI 柔性体目标 **0.12 mm**，以 18µm 铜作初步供电估算。实际铜厚、PI、胶、覆盖膜和公差由 FPC 厂提供叠层；KiCad 总厚设置不是已批准叠层。
- F.Cu 信号/电源，B.Cu GND 回流；静态安装中心线 **R0.8 mm**，不得压死折。双层铜对应弯曲半径必须获板厂确认；改网格地或铜厚后须重查电气。
- 元件岛背面补强和胶预算 **0.48 mm**，含柔性体总厚 **≤0.60 mm**，支撑 BTB 插合力。
- 金手指适配 AFE03-S21FMA-1H：21P、0.30 mm 间距、宽 6.60 mm，成品插入厚 **0.20±0.03 mm**；背面补强直段 **≥3.5 mm**。模型直段 3.848 mm，补强不跨弯。
- F.Cu 金手指中心跨度 6.0 mm，指宽 0.20 mm，露铜长 2.20 mm、距切边 0.30 mm。**与插座配线图复核接触面、金手指、覆盖膜开窗和边缘公差。** F.Mask/B.Mask 仅表达开窗意图，不是经过板厂补偿的覆盖膜激光文件。
- 表面处理/金厚由板厂结合插接及细间距焊接要求确认，本包没有指定耐插拔寿命。
- 柔性跨距无过孔；插头补强区 1 个接地孔，其余孔在元件岛。根部现在为斜线扩展；板厂若要求圆角/泪滴，须回传改图复核，不改变针序及端点位置。

## DRC 工艺下限

| 项目 | mm |
|---|---:|
| 最小线宽 / 铜间距 | 0.10 / 0.10 |
| 常用信号线宽 | 0.12 |
| 电源两脚汇合后跨距线宽 | 0.44 |
| 常规过孔焊盘 / 孔 | 0.40 / 0.20 |
| 3 个接地小过孔焊盘 / 孔 | **0.30 / 0.15** |
| 最小环宽 | **0.075** |
| 孔到其他铜最小间距 | **0.175** |
| 铜到板边最小间距 | 0.15 |

均为两层贯通金属化孔，不是盲埋微孔。若厂商不支持，应修改设计后重出文件，不能仅选较粗工艺。复位扇出处有过孔靠近/进入信号焊盘开窗，板厂需检查塞孔/覆盖及焊料流失，DRC 不能保证焊接良率。

Gerber 和钻孔共用辅助原点 (50,50)，对应元件岛左上角。金手指位于负 X，不能让平台裁掉。J2 局部中心 (3,12)，1 脚左上，长轴 Y。

## 装配及首次上电

J2 为 OK-23GF024-04；J1 为金手指，不另装插座。R10/R11 **DNP**。R7/R8 默认 0Ω。C2 选 0603 10µF / 10V / X5R或X7R、实物高≤0.8 mm；还需核对偏压后容值。其余见 BOM。

1. 断电核对主板 FPC2 接触面、金手指 1 脚、锁扣、厚度、供电对地阻值和两端针号；旧 LEDA/LEDK 不接屏。
2. 限流上电，按屏厂 CO5300 初始化流程控制 VCI_EN、LCD_RST、TP_RST。初期 QSPI≤10MHz、不使用 TE，再按波形和稳定性提速。
3. 测屏端 VBAT/VDD/TP_VDD、最大亮度/大面积白屏电流及主板 3.3 V 余量。70 mm、0.44 mm、18µm 电源铜约 0.15Ω，另有插座、回流及焊点电阻；尚未验证最差工况。
4. 先 1:1 纸模，再试装柔性板、屏幕原生尾巴和 BTB。折弯模型只检查包络，不能验证锁扣、触点、公母插合公差。

本版 ERC、DRC、未连接和原理图一致性问题均为 0。报告随审核包提供，但不包含实测点亮/可靠性结论。
