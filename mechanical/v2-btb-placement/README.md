# 第二版主板正面 BTB 位置评审

当前结论：可以在取消 U9 模组后预留一个正面 BTB 候选位置，但**尚不能冻结生产坐标**。现有屏幕 CAD 没有原生排线的精确实体，需在主板正面高度试折实物后确认落点和 1 脚。

## 建议预留位置

以现有主板 Edge.Cuts 中心线外包左上角为基准：KiCad **(128.868,67.647)**，名义板框 **46×76 mm**，X 向右、Y 向下。

| 项目 | 候选值 |
|---|---|
| 连接器 | OK-23GF024-04，24P 母座，与屏幕公座配对 |
| 放置面 | F.Cu，朝屏幕一面 |
| 基于主板板框的中心 | **X=30.00，Y=29.20 mm** |
| 当前 KiCad 绝对中心 | **X=158.868，Y=96.847 mm** |
| 外壳装配底面中心 | **(18.00,31.20,5.80) mm** |
| 长轴 | 沿主板 X，横向 |
| 预留区域 | 中心周围 **11×6 mm**，先不放裸芯片、晶振或其他元件 |

坐标转换为 `X_case=176.868-X_KiCad`、`Y_case=Y_KiCad-65.647`。所以 KiCad 顶视图的左/右与当前外壳平面坐标相反；不能把外壳 X18 当作主板局部 X18。

当前适配器封装旋转 **90°** 时，1 脚位于 KiCad 图中左下，局部 (27.8,30.4)；旋转 **270°** 时会变成右上。两种角度外形占位相同，但针序相反。此处只推荐长轴方向，**90°/270° 的最终选择须按屏幕原生排线的实际折回姿态核对**，不能沿用旧转接板的“1 脚左上”。

## 选择理由及实测边界

1. 将旧转接板的外壳 XY=(32,20) 投影到主板正面后，母座最大包络与现有 CARD2/TF 卡座相交约 1.146 mm³，不能直接照搬。
2. 新位置在 U9 模组原占位的下半部。保留模组时与其干涉；从评审中排除将被替换的 U9 后，母座最大包络以及 11×6×1.7 mm 操作预留区与其余现有模型没有体积干涉。没有模拟插合手指/工具的完整扫掠。
3. 方案假定屏幕横放后，原生自由尾巴朝机身左侧、靠屏幕下沿。按规格书第 5 页折弯示意图中的边距 5.15±0.5 mm、尾端宽 4 mm，尾巴轴线估算为外壳 Y≈`0.85+37.5-(5.15+4/2)=31.2 mm`。**这是示意图推算，不是厂家给定的主板连接器坐标**。X18 是在腾出空间内选的工程候选值，需实物调整。
4. 原转接板焊接基面 Z10.1；主板正面 Z5.8，低了 **4.3 mm**。低矮母座本身不能补这个高度，屏幕原生 FPC 必须形成新的三维弯曲路线。型号所称 0.8H 是公母插合高度，不是 4.3 mm 高度转接件。
5. 第二版裸芯片、射频匹配/天线、晶振、电源与去耦布局尚未设计；这份结果只确认候选母座区域相对于当前外壳和其余器件的空间关系。

## 文件

- `Q2_V2_BTB_Position_Study.FCStd`：独立 FreeCAD 评审副本。
- `placement-top.png/svg`：以 KiCad 顶视图表达的候选位置，包含板框基准及 TF/旧模组占位。
- `position-check.json`：坐标、碰撞结果和全部假设。
- `check_position.py`：可重建检查副本；现有主板和 L 版外壳文件保持原样。

在绘制第二版走线前，用实际 AM213 屏幕在 Z5.8 mm 的主板平面试折：避开原生元件区与钢片补强，不强拉、不折死；确认插合面、尾巴自然落点和 pin 1，再冻结 XY 与 90°/270°。若实屏实际朝另一侧出线，需要调整屏幕朝向或重选位置，不能只把本坐标镜像后直接投板。
