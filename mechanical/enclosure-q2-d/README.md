# Q2 修订 D：屏幕上移与完整外壳视图

本次把屏幕、保护盖板、屏幕开窗、胶框及屏幕排线出线位置一起向顶部移动 **1.5 mm**。外壳保持 **50×80×13.5 mm**，含盖板最高14.2 mm；默认显示完整机身、后盖、屏窗和操作环。

**现有PCB尚未适配这个外壳。** 之前C版默认视图及单独的屏幕连接检查模型隐藏了外壳，造成“没有外壳包住主板”的视觉印象；除此之外，原主板48×76/R1.2与50×80/R12外壳确实相交。外观图只表示结构外形，不能据此判断原PCB已经装得下。

## 本次修改

- LCD顶部由Y3.735移至Y2.235；外加保护盖板顶部由Y2.000移至Y0.500。0.5 mm是平面名义顶部余量，边缘滚圆处的实际局部支撑、胶粘与加工仍需试样验证。
- 上移全部3.866 mm会使LCD越过顶部0.131 mm、盖板越过1.866 mm，因此没有把屏幕直接推到壳体外。上移1.5后，屏幕及盖板仍在原机身外轮廓内，屏幕与壳体、操作板、电池无新增实体干涉。
- FPC2座体高度按已取得的钜硕原厂图由1.5改成1.0 mm。当前显示的是准确标称外包络，没有臆造插槽高度。
- 屏幕排线采用不横向剪切的46.14 mm中性线候选。上移后自然轴线Y20.400，原连接座Y18.034，仍差 **2.366 mm**；端点X/Z与弯曲半径仍为假设，未实现配合验证。连接器外包络重叠单独记录，不能作为插接成功证据。
- 原PCB、铜层和器件坐标未改写。PCB和外壳相交90.001444 mm³；元件包络也有冲突。`exports/current-PCB-conflicts.png`将相关区域标红。

保持接近Q2的外形，需要把主板板框、板角元件和排线通道一起重做；仅显示完整外壳或裁掉板框都不能解决布线/元件冲突。C版的47×76/R10.5目标板仍只作机械空间参考，未当成已改好的实际PCB。若保留原PCB及原大圆角壳体设计，试算56×86的壳体内腔仍与板角相交，58×88的板体空间才通过；这只是板体包络试算，不是已设计的大壳方案。

## 文件

- `ESP32S31_MP3_Q2_D.FCStd`：原生工程，默认完整外壳视图。
- `exports/exterior-D.png`、`front-D.png`：上移后的外观。
- `exports/current-PCB-conflicts.png`：实际旧PCB与半透明壳体的干涉视图。
- `exports/revision-D-review.png`：外观与现有板冲突并列说明。
- `exports/q2-d-*.step`、`.stl`：外壳、后盖、操作环和中心键；结构样件，未放行量产。
- `exports/assembly-D-current-PCB-CONFLICTS.step`：保留原PCB冲突的装配审查文件。
- `exports/validation.json`：逐项相交体积与FPC偏差；`exports/export-verification.json`：四个STEP重读有效、STL闭合和屏幕位移核验。

在 FreeCAD 中保存并关闭同名D版后运行 `Rebuild.FCMacro` 可重建。JSON为尺寸来源；原主板和原布局摘要的哈希发生变化时需更新冻结参考体。
