# 屏幕模型与 FPC2 配合核查

结论：**屏幕尾端的标称宽度、触点跨度与现有座的推荐 FPC 尺寸一致，但不能确认当前 C 版装配能直接插接。** 当前自然排线中心线横向错位 3.866 mm，绕板边路径还有干涉；屏幕端部厚度与引脚定义未提供。没有把一条横向剪切的示意排线当作真实可折叠的 FPC。

## 模型与结果

- `LCD209_dimensioned.FCStd`：按所给图建立的原生参数化屏幕模型；Parameters 可编辑。BL 36.33±0.1 ×43.45±0.1 ×1.46±0.1，LCD 36.13×43.25，AA 34.18×40.05，上边距1.05。排线伸出46.14±0.5、尾宽6.6±0.05、触点跨度6±0.03、露铜长2.5±0.3。
- `LCD_FPC2_fit_audit.FCStd`：现有主板坐标下的装配检查，橙色为不作横向剪切的排线候选，红色为实际 FPC2 包络及干涉。蓝色 `ProposedFPC2_Yplus3p866` 默认隐藏，可开启查看移位候选。
- `exports/lcd209-flat-reference.step`、`lcd209-module-only.step`：完整展开模型与仅模块模型。
- `exports/display-fit-review.png`：带尺寸及中心线偏差的说明图。
- `exports/fit-audit.json`、`verification.json`：尺寸、碰撞、STEP 重读验证；`pin-comparison.csv`：21针主板网络及对应屏幕功能待确认表。
- `exports/current-assembly-NOT-MATED.step`：现状检查模型，有已知干涉，**不是合格插接装配**。

## 原图中已知与未知

21 个触点跨6 mm，名义节距为0.3 mm。图中的 `0.3±0.03` 引线指向尾端边缘到触点位置，不能把它当作单个节距的公差。1号脚按原图放在正视图右侧，其余编号按21针连续推定。原图足以确定包络，不能从低分辨率接触图形反推完整金手指制造图。

外框R10、显示区R9、排线颈部18×12.8、本体厚0.12、内部玻璃/背光厚度拆分0.30/1.16、接触铜厚及宽度均为模型假设。金手指用接触区域表示，未声明其交错形状与座内弹片已经核对。模型中的0.12不是屏幕插入端总厚，补强层未作已知实物建模。单面胶0.03是否包含在LCM总厚中亦未确定，未额外增加模块高度。

## 原厂连接座核查

现有 KiCad 文件只读提取显示 FPC2 在 B.Cu，坐标(140.148,67.034)，90°；型号为 AFE03-S21FMA-1H。`reference/current-fpc2.json` 保存坐标、逐针网络与文件哈希。

使用[钜硕原厂 AFE03 系列机械图](https://datasheet.lcsc.com/datasheet/pdf/a3fef74488a86aba9513d2bb0e2e596c.pdf?productCode=C262542)，本地存为 `reference/AFE03-S21FMA-1H.pdf`。21针表格及推荐FPC图给出：

| 项目 | 连接座/推荐FPC | 用户屏幕图 | 判定 |
|---|---|---|---|
| 针数/名义节距 | 21 / 0.3 | 21针、6mm跨度推定0.3 | 标称一致 |
| 尾端宽度 | (N×0.3)+0.3 = 6.6±0.05 | 6.6±0.05 | 一致 |
| 触点跨度 | (N×0.3)−0.3 = 6±0.03 | 6±0.03 | 一致 |
| 接触区域长度 | 推荐图2.5 | 2.5±0.3 | 名义一致；交错图案待完整图确认 |
| 插入端总厚 | 0.20±0.03 | 未标 | 未确认 |
| 补强区长度 | 最少3.5 | 未标 | 未确认 |
| 接触形式 | 型号F=Lower，下接触 | 金手指在所示正视面；完整接触面说明缺失 | 须结合折叠方向核对 |
| 座体 | 7.9±0.1 ×3.2 ×1.0高 | 推荐另一个型号 OK-F302-21115 | 型号不同，不能仅凭节距宣布可替换 |

原厂焊盘图的 Circuit 1 在前侧长焊盘排，结合实际奇偶焊盘行，可以把正面插入口对应到 C 坐标的 +X 一侧；该方向与之前的候选路径一致。机械图未直接给出槽中心高度和插入止挡的整机坐标，本次只建准确外包络，**不虚构一个槽并据此报告“已经插入”**。C 版原先1.5 mm连接座高度是估计；此检查模型已改为1.0 mm。

## 对齐与折弯

C 装配坐标：x=149−KiCadX，y=KiCadY−49。屏幕横置左出线，尾部中心Y=3.735+36.33/2=21.900；FPC2触点行中心Y=67.034−49=18.034。差值**3.866 mm**。仅沿同一个横向轴绕板边翻折、再回折，不会消除这个偏差。对比表中21个端子均具有同样的Y偏差；没有把焊盘的X坐标误当作座内接触点X坐标。

旧C版示意用斜向剪切带把这段偏差接上，它不证明真实排线可以无拉伸展开。本检查模型用圆柱弯折、保持同一Y中心线，展开中性线长度46.14；弯曲半径0.65/0.675、端点Z3.70、端点X8.352均仍是空间研究假设。屏幕已标的±0.5长度公差和未提供的允许弯曲半径尚未做生产公差堆叠。

这条未侧移候选路径与当前板体相交1.9656 mm³，与ESP32包络相交6.912 mm³。板体来自源主板；ESP32高度沿用3.2 mm估计，因此后者是包络警示，不能当实物测量值。原FPC2座体与端部的重叠没有被计作插接成功。

为保留当前屏幕位置，一个简单的横向对齐候选是将 FPC2 沿 KiCad +Y 移动3.866到 **(140.148,70.900)**，保持90°与背面。**这只是对齐目标；尚未检查新位置邻近元件、焊盘间距、扇出或布线，未改写现有PCB。** 仍需重新给排线留板边绕行空间，并在屏幕完整FPC厚度、补强、金手指图形及21针定义确认后完成配合和电气检查。

## 验证与复现

屏幕原生尺寸和针序方向已检查；4份STEP均重读且几何有效。PCB文件SHA256仍为 `60deebc60149e9abd5f80077752135f7d0ae33c0fbd682f53f78e2fe683c044c`，未修改铜层/布线。

依次使用 KiCad Python 运行 `extract_board.py`；FreeCAD Python运行 `build_display.py`、`build_fit.py`、`verify.py`；GUI运行 `prepare_views.py`；普通Python/Pillow运行 `make_review.py`。构建前关闭同名检查文档。`prepare_sources.py` 记录了屏幕构建源相对于前版的生成方式，平常无需重跑。
