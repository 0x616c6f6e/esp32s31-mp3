# Q2 K 装入路径与结构修复版 — 2026-09-23

**本版用于树脂装机样件。J 版复查发现的装入障碍、局部薄壁和 LCD 无固定问题已在 K 版处理。** 完整静态检查未发现非预期实体干涉；分阶段装入的 66 个离散姿态全部通过；六套 STEP/STL 已从磁盘回读验证。可以提交 K 版文件作打样审核，不能视为已经通过厂家审核或实物装配验证。

整机 **50 × 81.5 × 15.1 mm（含前盖板）**，比 J 厚 0.9 mm；两块 PCB、接口、操作区中心及正面宽高保留。壳体本身最高 14.4 mm。打印上壳从装配 Z=1.2 起，因此其单件外包厚度为 13.2 mm，不等于整机厚度。

## 文件与修复内容

- `Q2_K_Assembly_Access.FCStd`：当前 FreeCAD 完整装配，含打印件、电子件、装配参考及参数表。主要结构由脚本构建的实体组成，不是完整草图约束树。
- `Q2_K_Assembly_Access.step`：整机交换模型，仅作装配参考，不可整体送印。
- **`Q2-K-assembly-sample.zip`**：五件必需打印件、一个可选螺母小样，各含 STEP/STL，加工说明及检查记录。
- `print-package/`：与 ZIP 一致的送印文件，单位 mm。每件独立局部原点；STEP 与 STL 是同件的两种格式，只选一种上传，避免重复下单。
- `front-assembled.png`、`shell-parts.png`、`back-internals.png`、`controls-mount-view.png`、`insert-section.png`：装配预览。

## 五金和胶贴

所有螺钉长度均指**头下长度**。合计 **9 颗螺钉＋3 片平垫＋2 颗铜螺母**。

| 位置 | 数量与规格 | 配合要求 |

| 小板到上壳 | **3 × M1.6×2.5，头径 ≤3.3、头高 ≤0.5 mm** | 每颗必须配下列垫片；不要用 3 mm 替代 |
| 小板平垫 | 3 × ID1.7 / OD4 / 厚0.3 mm | 置于螺钉头与 PCB 背面之间 |
| 后盖到上壳 | 2 × M1.6×6，头径 ≤3.2、头高 ≤0.5 mm | 配合两颗胶粘铜螺母 |
| 铜螺母 | 2 × M1.6×0.35，无头滚花，最大外径2.5、总长3.0 mm | 参考 In-saiL MT-M1.6x3.0-OD2.5；不能替换为外径3 mm款 |
| LCD 背胶 | 2 条 20×1.1×0.2 mm（含胶总厚） | 粘于 LCD 背面边缘与支撑台，不能覆盖 FPC 根部或顶压玻璃 |
| 右侧小板限位垫 | 沿用 0.2 mm 含胶绝缘垫 | 贴在侧边限位台与小板接触处 |
| 马达固定 | 底部0.1 mm 胶贴；托座右侧0.2 mm胶层 | 托座粘接面积约10.25 mm²，完全固化后再装主板 |

小板三个螺钉中心为 (6,51)、(6,67)、(44,67) mm；(44,51) 只作支撑，不装第四颗螺钉，否则会碰 FFC。小板底孔 Ø1.3，深 1.6 mm，封顶 0.9 mm，螺钉尖端距孔底名义 0.2 mm。采购螺钉先量头下长度和垫片厚度，试装不得顶穿面壳。

铜螺母先试配小样：从带缺角一端开始依次 Ø2.90、3.00、3.10 mm；正式壳体孔固定 Ø3.00。确认实际最大滚花直径/长度，以兼容树脂和黄铜的环氧胶冷粘，禁止热压、硬压。只在外壁少量上胶，避免胶进入内螺纹和 Ø1.8 余孔。装入至定位台阶，端面低于柱口 0.20 mm；保持同轴直至完全固化。

胶粘孔在装配 Z=1.85～5.05，螺母 Z=2.05～5.05；螺柱主段壁厚1.10、入口最薄0.95 mm。上部螺钉尖端 Z=6.65，距盲通道末端7.20有0.55 mm。下部柱已缩短到Z=6，螺钉尖端高出柱顶0.65 mm，处于已检查的空隙中，不是顶住盲孔。胶接强度和防转效果需小样验证，不能靠螺钉强拉螺母入孔。

规格依据：[In-saiL 螺母](https://www.ppmcn.com/mini-tech-inserts/)、[Formlabs 树脂嵌件胶粘方法](https://formlabs.com/blog/adding-screw-threads-3d-printed-parts/)。厂家热嵌孔尺寸不适用于本版的冷胶孔。

## 装配顺序与方向

以下坐标为 FreeCAD 装配坐标：X 增大为正面视图右侧，Y 增大朝 USB/耳机口，Z 增大朝屏幕前脸。数值为相对最终位置的移动量，勿按后视图左右直接套用。

1. **先处理空壳。** 去支撑、清洗并完全后固化，试配螺母并粘好。胶完全固化后再装电子件。马达托座、主板、控制排线和电池此时均不安装。
2. **装滑环。** 上壳正面朝下，用软垫保护。滑环相对最终位置向屏幕方向偏移3.5 mm，从后侧进入，先停在比最终位置低5 mm的高度；向下端平移3.5 mm回到中心，再朝前脸推至最终位置。此路线绕过底部缩短的螺柱。中央键随后从后侧直入，推杆朝小板。
3. **装小板。** 先贴右侧0.2 mm限位垫。小板相对最终位置 X=-1.3、Y=-5 mm 从后侧进入，停在 Z=-0.5 mm；保持X偏移，沿Y回到0；再沿Z上移0.5到支撑平面；最后沿X向右滑1.3 mm进入侧边限位台。装三颗 M1.6×2.5＋0.3 mm平垫。检查板平整、按键无预压且能回弹。不能从后侧垂直硬压进限位台。
4. **装马达托座。** 先把马达用0.1 mm胶固定在托座中，导线从左侧缺口引出；模块从后侧进入。托座右侧与壳内壁留0.2 mm胶层，底面 Z=6.1，马达中心(43,60.3)，马达底面Z=7.3。定位并粘接至完全固化，不要用耳机座或 PCB 顶住定位。此件必须在小板装好后安装，否则会挡小板路线。
5. **装屏幕。** LCD 从正面装入，先把排线经左侧通道引到内部。两条0.2 mm背胶落在上下支撑台上，LCD背面 Z=12.74。再装另购的46×40×0.6 mm透明盖板及原周边胶；盖板背面Z=14.5，与LCD正面留0.3 mm，不以盖板挤压固定LCD。
6. **装电池、绝缘和线束。** 使用已确认尺寸的电池；未选到满足成品包络的产品时，先用绝缘尺寸块验证。保留背部绝缘、可拆胶和线束应力释放。连接12P/0.5 mm/40 mm异面FFC及屏幕FPC，核对接触面和锁扣。
7. **装主板/后盖。** 主板先用四颗 M2×4 固定在后盖四柱，连好柔性线束和排线后，从后侧平行合入上壳。检查线束随盖移动、不夹线，再以两颗M1.6×6低扭矩锁紧。后盖合装检查不包含排线的真实弯曲应力或工具可达性，实际试装仍须观察。

## 沿用的电子件约束

- 主板和 CH32V006 C 版小板文件见 `source.json`；哈希均与当前 PCB 一致，本任务没有修改 PCB。
- **CN2/CN3 不装原弯脚插座，仍采用直接焊柔性线束方案**；原插座背部高度不适合薄壳。电池 CN2-1=VBAT、2=BAT_TS、3=GBAT；马达 CN3-1=MOTOR_OUT_P、2=MOTOR_OUT_N。保留原检测回路，焊接和接电前核对极性。
- 马达按 C08-005 LRA 最大 Ø8.1×3.45 mm 建模。驱动模式和校准沿用此前要求；其他直流纽扣马达不能只按外形替换。
- 电池仍是**采购空间，不是已验证成品**：含保护板、NTC、胶带和公差 ≤21×33×3 mm；另留0.3 mm增厚余量后，与U5仅约0.15 mm名义间距。原Liter-3020030仅为裸电芯候选。供方确认成品尺寸、电流和充电参数之前，不可挤压厚电池合盖。
- 电池与小板之间保留0.1 mm PET及0.2 mm可移除胶。CN2/CN3改线不表示充电固件已经适配该小容量电池。
- 屏幕外形36.33×43.45×1.46 mm及排线总长46.14 mm来自用户图纸。**宽排线根部长度13.8 mm、过渡轮廓和弯曲半径仍为建模假设**，原图没有完整标注；需要实物检验。PCB插接端位置不变，不能把名义几何可达理解为已经确认实物兼容。
- 40 mm控制FFC型号、接触面、插入深度和触摸灵敏度仍需实物验证；触摸面变厚后需要重新标定CH32固件。

## 验证结果与边界

- `fit-check.json`：188个检查对象，按每对实体检查复合体；非预期静态干涉0、无效实体0、电池增厚包络干涉0。仅豁免明确的螺纹配合、连接器插入及线端连接。
- `assembly-path-check.json`：滑环16、中央键8、小板20、马达模块8、LCD7、后盖/主板7个姿态，均无干涉。**这是66个分阶段离散采样，不是连续扫掠证明**，也不包含软排线变形和工具空间验证。
- 按键下压0.33 mm、滑环四向摇摆约0.727°的名义状态均通过；实际开关力、树脂弹性和回弹需要样机测试。
- `detail-check.json`：止脱边、螺丝承压厚度、三处螺孔封顶、LCD支撑及胶贴接触、螺母后侧装入和后盖螺钉通道均通过。
- `export-readback-check.json`：六件均为有效单实体、闭合单连通STL，无自交、非流形边及法向错误；回读STEP与最终FCStd打印件几何差为0。ZIP经CRC及SHA256校验。

结论是**可进行 K 版装机样件打样审核**。尚未做制造公差堆栈、树脂强度、胶接拉拔、扭矩、跌落、插头实物适配或续航/发热试验；J版的暂缓结论保留作历史，不应与K版混用。
