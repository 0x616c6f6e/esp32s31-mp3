# Q2 修订 C：主板翻转与独立操作小板

> 后续屏幕配合核查见 `../display-fit/README.md`。C版FPC2高度1.5 mm已被原厂图纠正为1.0 mm；C版横向剪切排线不能证明可插接。现有屏幕自然排线与座中心横向差3.866 mm，且绕板边路径有干涉。最新尺寸模型和检查模型在 `../display-fit/`，本目录保留C版结构方案快照。

本版按用户确认的结构修正装配：**主板 ESP32 模组一面朝屏幕；模组背面的 FPC2 是屏幕连接器，朝向后盖。屏幕排线从主板侧边绕到该连接器。滑环与五个按键放在同一块独立小板上，再通过另一条 FPC 连接主板。**

Q2 外观与屏幕尺寸沿用 B 版。主板是整体刚性翻转和高度调整，元件跟随一起变换，未改写 KiCad 布线文件。操作板目前只完成机械外形与器件空间，尚无原理图、铜层、引脚定义或布线。

## 文件

- `ESP32S31_MP3_Q2_C.FCStd`：FreeCAD 原生工程；默认显示内部装配。`Parameters` 驱动板框、孔、外壳等原生特征；部件与排线路径快照须重建同步。
- `exports/assembly-review.png`：本版装配说明图。
- `exports/stack-with-screen.png`：含半透明屏幕的正面层叠；`internal-front.png`：移去屏幕看主板与操作板。
- `exports/screen-fpc-rear.png`：从背面观察屏幕排线与原 FPC2；橙色为屏幕 FPC，蓝色为独立操作板 FPC 通道。
- `exports/control-board-mechanical.step`、`control-board-outline.dxf`、`control-board-dimensions.svg`、`control-board-features.csv`：供后续小板 PCB 设计使用。STEP 使用整机坐标；DXF / CSV 使用小板局部坐标。
- `exports/assembly-C-with-current-PCB.step`：包含当前主板的装配参考，**包含已知冲突，不是已放行的生产装配**。
- `exports/q2-c-*.step` / `.stl`：修改后机身、后盖、滑环摇板面片及中心键。只用于结构试样。
- `exports/validation.json`、`export-verification.json`：几何和导出验证结果。

## 主板方向与厚度层叠

坐标沿用机械工程：x/y 为板面方向，+Y 朝底部接口，+Z 朝屏幕。前视图的左右与从主板背面看相反，请以 CAD 坐标或器件位号辨认。

| 部分 | 本版位置或尺寸 |
|---|---|
| 主板名义后表面 / 前表面 | z = 4.2 / 5.2 mm |
| ESP32 包络 | z = 5.2～8.4 mm，朝屏幕；高度仍按 3.2 mm 估算 |
| 屏幕 FPC2 包络 | z = 2.7～4.2 mm，朝后盖；XY 来自原封装 |
| 屏幕 LCM | z = 11.84～13.30 mm；43.45 横向 × 36.33 纵向 |
| 电池预留 | 26 × 34 × 3 mm；(x,y,z) = (8.3,35.5,7.8)，位于主板与操作板之间 |
| 操作板 | z = 11.1～11.9 mm |
| 外壳 | 50 × 80 × 13.5 mm；含盖板最大 14.2 mm |

从旧 A/B 装配坐标到 C 的主板转换为 `x_C=50-x_old, y_C=y_old, z_C=12.3-z_old`。该转换同时应用到板体和全部元件，底部 USB / 耳机孔以及 TF 槽也同步调整。主板导出实体厚度为 0.91 mm，层叠按名义 1.0 mm 预留。

## 独立滑环与按键板

板框 **44 × 34 × 0.8 mm、R10**，小板局部原点对应机身 `(3,44.3)`，局部 +X/+Y 与机身同向。DXF 以毫米导出，包含闭合板边和四个直径 1.8 mm 的 NPTH 孔，尚未转换为真实 KiCad 板。

| 项目 | 局部 x / y（mm） | 说明 |
|---|---|---|
| 安装孔 1 / 2 | (3,8.7) / (41,8.7) | D1.8，配 M1.6 螺钉方案 |
| 安装孔 3 / 4 | (3,24.7) / (41,24.7) | D1.8，配 M1.6 螺钉方案 |
| 中心电源键 | (22,17) | 正面 |
| 返回 / 播放暂停 | (22,4) / (22,30) | 正面 |
| 上一曲 / 下一曲 | (35,17) / (9,17) | 位号按整机前视方向命名 |
| FPC 座中心 | (37.75,5.7) | 小板背面；7.5 × 3 × 1 mm 占位 |

滑环感应带示意为内径 21 / 外径 31 mm、12 分区；**只是机械位置示意，不是设计好的铜箔电极**。后续还需感应 IC、按键电路、屏蔽、接地、接口定义与 PCB 布线。五个开关按 3 × 3 × 0.55 mm 低矮器件预留，未指定采购型号。

壳体新增四个小板支柱，中心键独立保留，环面片带四向压杆与环形防脱边。摇板的弹性、复位、行程及薄边强度尚未实物验证；0.10 mm 压杆间隙与最薄止挡不能直接视为量产公差。

## 两条 FPC 分开

**屏幕 FPC（橙色）**：屏幕横向安装，并选择排线从机身 x 较小的一侧引出；从正面绕左板边进入背面，经过余长回折后到达原 FPC2。连接端示意在 `(8.352,18.034,3.25)`，按 2.5 mm 插入长度放入假定插槽。本版不再把屏幕插到另行假设的新接口位置。

路径中性线长度按用户标注的 **46.14 mm** 计算，展开模型仍见 `../enclosure-q2/LCD209_36x43.FCStd`。侧边 R0.65、回折 R0.45、排线横向错位和插槽高度均为布局假设；图中错位段是空间通道，不代表已证明可展开、无拉伸的折叠工艺。实际 FPC 接触面、补强片、最小静态弯折半径、连接器开口方向及卡扣操作空间必须按实物复核。

**操作板 FPC（蓝色）**：小板背面 FPC 座连接到主板正面新增接口预留。主板占位中心 `(40.75,35.5)`、7.5 × 3 × 1 mm，当前 KiCad **还没有这个连接器**。预留 6.5 mm 宽通道，排线长度先按 25 mm 选型空间考虑。蓝色直角折线表示通道，未按真实弯曲半径建制造级排线；引脚数、接触方向和有效插入长度待电路/连接器选型后确定。

## 已验证与待改板项

新壳、操作板、电池占位、五个开关、两条通道等所列新增几何相交检查通过。按模型，电池到操作板间隙 0.3 mm、耳机座到操作板 0.4 mm、中心开关到压杆 0.1 mm。这些依赖估算的器件高度，不能取代实物公差验证。

仍有与当前主板有关的冲突，已建红色实体：

1. 旧 48 × 76 / R1.2 板角与 Q2 大圆角机身不匹配，板体相交约 90.001444 mm³；U9/H1/C5/C58/CN1 的保守元件包络也有壳体冲突。
2. 绕板边屏幕排线通道与旧板边相交 1.9656 mm³，与 U9 包络相交 6.912 mm³。需在后续主板布局中给侧边排线让位；不能直接按当前形状折排线装机。
3. 天线区域仍被屏幕金属背板覆盖，需要射频布局复核。电池型号/容量、开关高度、FPC 座及接触面还需落实。

逐器件报告排除了屏幕排线插入 FPC2 的预期重叠；总包络相交列表中的 FPC2 项包含连接器包络内部的插接空间，不应当作额外器件冲突。`entire_current_hardware_fits=false` 保留了整机未适配完成的状态。

STEP 重导入有效，四个打印样件 STL 封闭，操作板 DXF 经 FreeCAD 重导入尺寸为 44 × 34 mm。原生操作板宽度 44→44.4→44 mm 重算/恢复通过；并核对了 ESP32 在前、FPC2 在后的 Z 范围。未变更主板 KiCad 文件，也未实现小板电路。

## 重建

保存并关闭 C 文档后运行 `Rebuild.FCMacro`；JSON 是重建参数来源。FPC、元件包络、电极示意及爆炸图是脚本快照，不能只修改表格就认为它们同步更新。`reference/source-manifest.json` 锁定主板及布局数据哈希；改板后必须刷新 BREP 参考形状。

`make_review.py` 由带 Pillow 的 Python 生成预览组合图和小板尺寸图。B 版外观参考、用户 LCD 图片及 Q2 官方说明书继续保存在 `../enclosure-q2/`，C 版不覆盖它们。
