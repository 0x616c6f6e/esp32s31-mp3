# Q2 L：2.13 英寸 AM213 屏幕适配

已按项目中的 `AM_213_Q410502_LK_b82450b641.pdf` 更新屏幕总成、面壳开孔及固定方式，保留已生产主板与按键板。**当前是机械适配版，含转接板空间预留；不是可直接装机生产的完整定版。** 新屏24针BTB不能插入原21针FPC2，有源转接板及两端排线仍需完成。

当前工程：**`Q2_L_AM213_Adapter_Study.FCStd`**。K版保留为旧2.09英寸屏历史工程，不适用于本次新屏。

屏幕正面最高Z=15.1、盖板背面Z=13.8、壳内胶台Z=13.6、光学总成背面Z=12.82 mm。模型按0.805 mm屏体＋0.175 mm OCA＋1.30 mm盖板分层，使总厚与规格书四舍五入后的2.28 mm一致；这0.005 mm并非额外零件。

屏幕在L版首次适配基础上**下移0.50 mm**，同步移动开孔、胶台、光学总成及背面FPC包络。此次按圆角处的视觉留白调整：原直边距虽相等，但上方圆角与机身曲率不同，留白偏窄。下移后盖板上圆角至面壳外缘的平面最短距离约1.27 mm，左右直边约1.30 mm（按Z=14.4前表面轮廓测量）；扣除0.25 mm装入缝后，可见实体边框约1.02/1.05 mm。这里的视觉均衡不等于三个方向的外包直边尺寸都相等。

尺寸取自规格书第3页及第5页完整总成图。盖板和裸屏圆角未标注半径，按第5页矢量轮廓近似为相切圆弧；盖板R约9.95 mm，裸屏左右角约R9.0/R8.42。盖板矢量采样点落在解析模型外的最大距离约0.052 mm。**这是图形近似，不是厂家尺寸公差保证**，取得厂家DXF/实物后仍需复核圆角。

## 屏幕背面与转接板

规格书显示该屏出厂把带元件FPC折到屏幕后方，不能使用旧屏的单条平整46.14 mm排线路径。本版删除旧路径，在屏幕后设置保守元件/FPC包络，向后预留1.52 mm（含图示1.42 mm局部高度与0.10 mm余量）。其形状是占位，不是FPC精确实形。

转接板预留位于装配坐标 **X29～46、Y8～30、Z9.5～10.1 mm**，尺寸17×22×0.6 mm。板下元件允许包络0.9 mm，板上连接器暂留0.8 mm。模型蓝色是板框、橙色是元件空间，均不是已经布线的PCB。当前检查中板上连接器包络至屏幕后包络名义间距0.4 mm；屏体向后增加0.2 mm后仍无实体交叠，但这不是完整制造公差堆栈。

**尚未建成**：新屏伸出的自由尾线到转接板的实际折弯、21针输入线到主板背面FPC2的路线、转接板固定座及准确母座模型。保留这些待定项，避免用一条虚构排线宣称两端已连接。电路及接线方案见 [转接板规划](../../hardware-display-adapter/README.md)。

## 装配变化

后盖、滑环、中央键、马达托座与K版几何完全一致；只有上壳/屏幕结构变化。五金仍为：主板4颗M2×4、小板3颗M1.6×2.5＋3片0.3 mm平垫、后盖2颗M1.6×6＋2颗OD2.5/L3的M1.6胶粘铜螺母。孔、头部尺寸及胶粘要求沿用 [K版说明](../enclosure-final-k/README.md)。

- 滑环先向屏幕偏3.5 mm，从后侧进入至低于终位5 mm，再移回中心并向前就位；中央键随后装入。
- **L版小板进入偏移改为 X=-1.3、Y=-3.0 mm**，不能沿用K版Y=-5路线。推至比终位低0.5 mm，再沿Y回到0、沿Z抬0.5 mm，最后向右滑1.3 mm进限位台，装三颗带平垫螺钉。
- 马达托座仍在小板之后安装。屏幕一体总成从前侧放入，胶贴只作用于盖板黑边台阶，不能在触摸盖板外再叠一块旧透明板。
- 转接板实际固定及排线接好后，主板/后盖才合装；该步骤仍等待实际转接设计。
