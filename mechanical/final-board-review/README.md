## 马达调整候选

另外计算了马达及支架整体平移的候选位置，**尚未改动当前检查装配**，以保留问题现场。壳体中心 **(43,60) mm** 是可继续细化的候选：对现有模型检查无干涉，到耳机座/小板 J1/控制排线的最小间隙约 **0.816 mm**。这只验证名义包络；支架与壳体的连接方式、实际马达公差及引线仍需重新设计，不能直接平移后打印。

## 模型来源与检查范围

最终主板引用的 `EASYEDA_MODELS` 路径缺少对应 STEP 文件。本目录在导出副本中补入 Git 历史保存的同封装名义模型，原 PCB 和用户删除的历史目录均未恢复或覆盖。模型文件及原许可说明在 `models3d/`。

U10 缺少原厂模型，按原引用文件名使用 **7.9×5.3×1.9 mm** 保守矩形包络，包含引脚跨度；不是厂家公差模型。其他同封装模型也只支持名义空间检查。CN2/CN3 无可靠高度，没有虚构“已通过”的模型。

外壳基于 F 版及上一轮按键板适配后的内部修改，包含马达 Y=62 的现状和控制 FFC 后盖局部避让。排线与其插座内部的预期插入区域不算干涉；其他 PCB、元件、屏幕、后盖、马达、电池、按键机构、排线均参加对应检查。电池/马达线束、USB/耳机外部插头的插拔包络、结构强度和制造公差未作完整验证。

## 文件

- `Q2_Final_Mainboard_Assembly.FCStd`：导入两板后的 FreeCAD 检查装配，保留问题位置。
- `assembly-review.png`：两板及外壳内部视图。
- `motor-jack-conflict.png`：马达与耳机座干涉近景，红色为重叠区域。
- `display-flex-conflict.png`：C13 与屏幕排线干涉近景；排线裁剪片段仅用于展示，不是修改后的排线路径。
- `fit-check.json`：完整几何结果、坐标、源文件散列和候选位置检查。
- `mainboard-reference.json`：逐封装模型映射、坐标及缺失项。
- `mainboard-layout-reference.step` / `controls-populated.step`：由对应 PCB 导出的两板 STEP。
- `mainboard-model-reference.kicad_pcb`：仅用于导出模型的副本，不是最终电气工程。

本目录是**装配检查版本，存在已记录干涉**。这里的外壳 STEP/STL 是检查现状的导出，不是修复后的生产文件。重建顺序：`build_u10.py` → `export_mainboard_reference.py` → KiCad CLI 导出两板 STEP → `build_review.py` → `annotate_review.py` → FreeCAD GUI 运行 `prepare_views.py`。`mounting_adjustment.py` 固定应用 SCREW3 的绝对新坐标，重复重建不会累积偏移。单独应用后盖改动用 `shift_screw3.py`，外观包同步用 `../appearance-prototype-v1/update_screw3.py`。不要把本目录导出副本覆盖到用户最终主板工程。
