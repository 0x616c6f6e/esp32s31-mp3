# 3D model sources and attribution

`vendor/` contains unmodified STEP files from the locally installed official KiCad 10 model library, maintained by the KiCad library community. Original copyright and license notices remain in those STEP headers. The model manifest records the original filename, source-library footprint and SHA-256.

KiCad models use **CC-BY-SA 4.0 with the KiCad electronic-design exception**. See [KiCad library licensing](https://www.kicad.org/libraries/license/) and the [CC-BY-SA 4.0 legal text](https://creativecommons.org/licenses/by-sa/4.0/legalcode). The project-local STEP files derived from these models have only package-coordinate rotations applied; those derived library files retain the same licensing terms and attribution as their respective source files.

The other project-local models were generated by `../../hardware-q2/scripts/build_3d_models.py` from the project footprint dimensions and the drawing references listed in `model-manifest.json`. Their generator is included with the project; these generated model files are provided under CC-BY-SA 4.0 with the same electronic-design exception. They are not manufacturer-supplied CAD. In particular, connector internals, assumed heights and solder-terminal illustrations must not be treated as certified manufacturing geometry.

Dimensional references:

- Espressif ESP32-S31-WROOM-3 & WROOM-3U datasheet v0.7, Figure 10-1, local copy `../../hardware/reference/esp32-s31-wroom-3.pdf`. [Official datasheet](https://documentation.espressif.com/esp32-s31-wroom-3_wroom-3u_datasheet_en.html).
- JUSHUO AFE03-S series connector drawing, 21-position row, local copy `../../mechanical/display-fit/reference/AFE03-S21FMA-1H.pdf`.
- Existing project footprint Fab outlines, numbered pads, and the names of the missing EasyEDA models. These establish the source of an approximation, not verification of the actual ordered component.

In this placement variant, seven standard model rotations were re-exported and verified by ../scripts/align_standard_models.FCMacro. See ../output/model-orientation-validation.json.

The two JST ACH mated-envelope STEP models are original simplified geometry generated by `../scripts/build_ach_models.py` using dimensions from the [JST ACH catalog](https://www.jst-mfg.com/product/pdf/eng/eACH.pdf). They are not KiCad standard STEP models or manufacturer CAD. They use the same CC-BY-SA 4.0 electronic-design exception terms as other project-generated models. Their corresponding footprint pad layouts are copied from the installed KiCad 10 Connector_JST library.
